## Overview

Developed an Android application in Java that replicates an online platform for a pizza store. The app provides a complete ordering experience with menu browsing, customization, and order management.

## Key Features

- **Menu Browsing**: Browse available pizza options with descriptions and pricing
- **Order Customization**: Select sizes, toppings, and special instructions
- **Order Management**: Cart functionality with order review and placement
- **Android Native**: Built with Android SDK and Java for native performance

## Tech Stack

- **Language**: Java
- **Platform**: Android SDK
- **IDE**: Android Studio
