## Overview

A real-time stock market price-alert program built in Python featuring interactive search, top views, above/below threshold alerts, and an algorithm to determine the best time to buy/sell certain stocks. Currently in active development.

## Key Features

- **Interactive Search**: Search and browse stock tickers with real-time price data
- **Threshold Alerts**: Configure above/below price alerts for monitored stocks
- **Buy/Sell Algorithm**: Algorithmic analysis to suggest optimal buy and sell timing
- **Top Views**: Dashboard showing most-viewed and trending stocks

## Tech Stack

- **Language**: Python
- **Data**: Real-time stock market APIs
- **Analysis**: Custom algorithmic trading signals
