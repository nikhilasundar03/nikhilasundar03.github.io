Implemented Meta's Prophet to accurately forecast time series data using dates and anomalies. This project was submitted to Rutgers Data Science Club's Fall 2023 Datathon and won the award for most advanced/unique algorithm and code overall.

- **Award-Winning**: Recognized for most advanced/unique algorithm at Rutgers Datathon
